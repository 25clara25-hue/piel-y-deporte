# Piel y Deporte

Prototipo de aplicación web propuesto para el área de Dermatología y Deporte de la Fundación Piel Sana de la AEDV.

**Prototipo pendiente de revisión y validación por la Fundación.** No sustituye la valoración médica.

- `index.html`: aplicación completa (contenidos, reglas de recomendación y proveedor UV separados en bloques del script).
- `sw.js`: caché mínima para abrir los contenidos sin conexión.

Configuración en el bloque `CONFIG` al principio del script de `index.html`.
